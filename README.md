# Jonas Valdellon — Personal Portfolio

A responsive, single-page portfolio made with HTML, CSS, and vanilla JavaScript. It includes a flip-style profile ID card, orbit effects, live portrait scan animation, responsive navigation, scroll reveals, and clickable project screenshot galleries.

## Publish the website

1. Download and extract the portfolio ZIP shared in the project conversation.
2. Clone this repository:

   ```bash
   git clone https://github.com/ValMarco-Org47/val-portfolio.git
   ```

3. Copy all files from the extracted portfolio folder (`index.html`, `style.css`, `script.js`, `README.md`, and `assets/`) into the cloned `val-portfolio` folder. Allow the README to be replaced.
4. Open the cloned folder in VS Code. In **Terminal → New Terminal**, run:

   ```bash
   git add .
   git commit -m "Add personal portfolio website"
   git push origin main
   ```

5. In GitHub, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
6. After deployment, the site should be available at:

   `https://valmarco-org47.github.io/val-portfolio/`

## Project files

- `index.html` — portfolio structure and content
- `style.css` — colors, layout, responsive design, and animations
- `script.js` — card flip, navigation, scroll reveal, and screenshot lightboxes
- `assets/` — profile portrait and PATAG / ResQNest screenshots

The project requires no Node.js, npm, or frontend framework.
